  Building VC compilers
====================
A Visual C++ 6 project (AMakeAllEMFx.dsp) and a workspace (AMakeAllEMFx.dsw) are
ready to build.

1. First read the instructions in the file SCGenInclude.h to set INCLUDE paths

2. Then build and enjoy!

Note: the building process will register SCEMFAx.ocx.

Other compilers
====================
I would be pleased to receive make files and incorporate them to the distribution.
